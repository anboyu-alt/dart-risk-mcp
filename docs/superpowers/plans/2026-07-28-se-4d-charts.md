# SE-4d: 시각화 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 표는 데이터를 옮겨놓을 뿐 정보를 주지 못한다. 시각화할 수 있는 데이터에 그림을 얹어, 사람이 한눈에 흐름을 읽을 수 있게 한다.

**Architecture:** Chart.js 4를 **저장소에 넣어(vendoring)** 쓴다 — CDN이 아니다. 데이터 가공은 `app.js`의 **순수 함수**로 두고 node로 검증하며, 캔버스 렌더만 `ui.js`가 맡는다. **표는 없애지 않고 차트를 그 위에 얹는다.**

**Tech Stack:** HTML + 순수 JS + **Chart.js 4.5.1 (MIT, 저장소 반입)**, 테스트는 `unittest` + `node` 서브프로세스

## 이 계획이 존재하는 이유

SE-4c로 화면이 읽히게 됐지만, 사용자가 정확히 짚었다:

> 지금 화면만 봐도 너는 오정강 대표의 지분이 시간순으로 보인다고 했잖아. 그런데 사람은 그렇게 빠르고 정확한 정보 습득이 안 됨. 시각적으로 표현할 수 있는 데이터가 들어오는데 그걸 그대로 보여주기만 하면 정보로서의 가치가 떨어져.

**AI가 표를 읽어줘야 알 수 있다면 화면이 제 역할을 못 하고 있는 것이다.**

---

## Global Constraints

**⚠️ 이전 계획들의 제약 하나가 바뀐다.** SE-4b·SE-4c는 "외부 CDN·빌드 스텝·프레임워크·npm 의존성 금지"였다. 진짜 의도는 **자체 완결성**이었지 "라이브러리 금지"가 아니었다(`scripts/build_network_html.py`도 *"자체 완결형 HTML(외부 CDN 없음)"*이라고 적혀 있다). 그래서 이렇게 고친다:

- **외부 런타임 의존 금지.** 라이브러리를 쓰려면 **파일을 저장소에 넣는다.** CDN `<script src="https://...">` 금지, npm 금지, 빌드 스텝 금지는 그대로다.
- `dart_risk_mcp/` core를 **수정하지 않는다.** `se_server/` API 계약도 **바꾸지 않는다** — 소비만 한다. 바꿔야 할 이유를 발견하면 **멈추고 보고한다.**
- **표를 없애지 않는다.** Chart.js는 canvas에 그리므로 차트 안의 숫자는 **복사도 검색도 안 된다.** 차트는 흐름을 보여주고, 정확한 값은 아래 표가 책임진다.
- **데이터를 조용히 숨기지 않는다.** 차트로 못 그리는 데이터는 표로 남는다.
- **점수·등급·판정 금지**(v0.8.5). 아래 "판정선" 절을 반드시 읽을 것.
- **사용자·API 데이터는 `textContent`로만 DOM에 넣는다.** 데이터가 섞인 `innerHTML`·`outerHTML`·`insertAdjacentHTML`·`document.write` 금지.
- **실명 취급 불변식 유지** — `showGate()`가 패널·본문·헤더·바·목차·기업 개요를 비우는 성질(로그아웃·세션 만료 시 이전 사용자 실명 잔류 방지). **차트도 이 정리에 포함돼야 한다.**
- **자산 참조는 루트 기준 절대경로**(`/se/...`). `trailingSlash:false` 때문에 상대경로는 404가 된다 — 실제로 겪은 사고다.
- 주석·UI 문구는 **한국어**. 테스트는 `unittest.TestCase`, 실제 네트워크 호출 없음.

## 판정선 — 이 계획에서 가장 조심할 것

차트는 판정을 **매우 쉽게** 만든다. 그래서 경계를 명시한다.

| 해도 되는 것 (사실) | 하면 안 되는 것 (판정) |
|---|---|
| 지분율 곡선을 그린다 | 급락 구간을 빨갛게 칠한다 |
| 계열마다 다른 색을 준다 | "위험" 색(빨강)을 값에 따라 붙인다 |
| 축에 실제 값 범위를 쓴다 | 임계선(예: 5%)을 긋고 넘으면 강조한다 |
| 툴팁에 원본 수치를 보여준다 | "급감"·"이상"·"주의" 같은 라벨을 단다 |
| 시간순으로 점을 잇는다 | 추세선·예측선을 그린다 |

**색은 계열 구분 용도로만 쓴다.** 기존 CSS 변수 `--c0`~`--c8`이 그 목적으로 이미 있다. `--red`는 값 판정에 쓰지 않는다.

사용자가 그림을 보고 스스로 판단하게 두는 것이 이 도구의 방식이다.

- Test: `tests/se/test_se_page_assets.py`

**Interfaces:**
- Produces: 전역 `Chart` (UMD). 이후 태스크가 쓴다.

**받는 방법** (빌드 스텝을 만들지 않는다 — 한 번 받아 커밋한다):

```
https://cdn.jsdelivr.net/npm/chart.js@4.5.1/dist/chart.umd.js
```

**`docs/tool/se/vendor/README.md`에 적을 것:** 출처 URL, 버전(4.5.1), 라이선스(MIT), 왜 CDN이 아니라 파일로 두는지(외부에 접속 기록을 남기지 않기 위해), 갱신 방법, 그리고 **파일의 SHA-384 체크섬**.

**체크섬을 남기는 이유.** CDN에서 불러올 때는 `integrity="sha384-..."`로 무결성을 검증한다. 파일을 반입하면 그 장치가 사라지므로 대신 체크섬을 기록에 남긴다. 이걸로 얻는 것:

- 파일이 조용히 바뀌면 테스트가 깨진다(사고든 고의든)
- 교체가 의도적 행위가 되어 diff에 드러난다
- 리뷰어가 **npm/jsdelivr가 공표한 integrity 값과 대조**해 진짜 배포본인지 확인할 수 있다

받을 때 확인하는 법:

```bash
python -c "import hashlib,base64,pathlib;   d=pathlib.Path('docs/tool/se/vendor/chart.umd.js').read_bytes();   print('sha384-'+base64.b64encode(hashlib.sha384(d).digest()).decode())"
```

출력값을 README에 적고, 아래 테스트가 그 값을 강제한다.

**`index.html`의 스크립트 순서:**

```html
<script src="/se/vendor/chart.umd.js"></script>
<script src="/se/app.js"></script>
<script src="/se/ui.js"></script>
```

**루트 절대경로여야 한다.** `trailingSlash:false`가 `/se/`를 `/se`로 되돌리므로 상대경로는 404가 된다 — 실제로 겪은 사고이며 `TestAssetPathsSurviveTrailingSlashRedirect`가 이미 막고 있다.

```python
class TestVendoredChartLibrary(unittest.TestCase):
    """라이브러리는 저장소에 넣는다 — CDN에서 불러오지 않는다.

    인가된 사람만 쓰는 서비스라, 외부 CDN이 페이지 접속 기록(IP·리퍼러)을
    갖는 것을 피한다. 파일을 고정해 두면 공급망 위험도 사라지고 CDN 장애와
    무관해진다. 빌드 스텝은 여전히 없다 — 한 번 받아 커밋할 뿐이다.
    """

    _VENDOR = _SE / "vendor"

    def test_chart_library_file_is_present(self):
        """파일이 없으면 아래 검사들이 공허하게 통과한다."""
        self.assertTrue((self._VENDOR / "chart.umd.js").exists(),
                        "vendor/chart.umd.js가 없습니다")

    def test_vendor_readme_records_source_and_license(self):
        """어디서 받았고 무슨 라이선스인지 남기지 않으면 갱신도 감사도 못 한다."""
        readme = (self._VENDOR / "README.md").read_text(encoding="utf-8")
        for token in ("4.5.1", "MIT", "chart.js"):
            self.assertIn(token, readme, f"vendor/README.md에 {token}이 없습니다")

    def test_library_is_loaded_from_a_root_absolute_local_path(self):
        html = _sources()["index.html"]
        m = re.search(r'<script src="([^"]*chart[^"]*)"', html)
        self.assertIsNotNone(m, "index.html이 차트 라이브러리를 불러오지 않습니다")
        src = m.group(1)
        self.assertFalse(src.startswith(("http://", "https://", "//")),
                         f"CDN에서 불러오고 있습니다: {src}")
        self.assertTrue(src.startswith("/se/"),
                        f"루트 절대경로여야 합니다(trailingSlash:false): {src}")

    def test_library_loads_before_our_scripts(self):
        """app.js·ui.js가 Chart를 참조하므로 먼저 로드돼야 한다."""
        html = _sources()["index.html"]
        lib = html.index("chart.umd.js")
        for name in ("/se/app.js", "/se/ui.js"):
            self.assertLess(lib, html.index(name), f"{name}보다 뒤에 로드됩니다")

    def test_library_file_matches_the_recorded_checksum(self):
        """반입한 파일이 조용히 바뀌지 않았는지 확인한다.

        CDN에서 불러오면 `integrity="sha384-..."`가 무결성을 지켜준다.
        파일로 반입하면 그 장치가 없어지므로 체크섬을 기록에 남기고
        여기서 강제한다. 리뷰어는 이 값을 npm/jsdelivr가 공표한 integrity
        값과 대조해 진짜 배포본인지 확인할 수 있다.
        """
        import base64
        import hashlib

        blob = (self._VENDOR / "chart.umd.js").read_bytes()
        actual = "sha384-" + base64.b64encode(hashlib.sha384(blob).digest()).decode()
        readme = (self._VENDOR / "README.md").read_text(encoding="utf-8")
        self.assertIn(actual, readme,
                      "반입한 파일이 README에 적힌 체크섬과 다릅니다.
"
                      f"  실제: {actual}
"
                      "  의도한 교체라면 README의 값을 갱신하세요.")

    def test_no_second_runtime_dependency_sneaks_in(self):
        """시간축 어댑터 같은 것이 추가되면 알아차려야 한다.

        Chart.js의 `time` scale은 별도 어댑터를 요구한다. 우리는 날짜를
        문자열 라벨로 만들어 `category` 축을 쓰므로 어댑터가 필요 없다.
        """
        names = sorted(p.name for p in self._VENDOR.glob("*.js"))
        self.assertEqual(names, ["chart.umd.js"],
                         f"vendor에 예상 밖 파일이 있습니다: {names}")
```

**`_sources()`가 `*.html`·`*.js`만 보므로 `vendor/`의 파일은 기존 검사(외부 URL·판정 어휘 등)에 걸리지 않는다.** `_SE.glob()`는 하위 디렉토리를 훑지 않기 때문이다. 이건 의도한 것이다 — 남의 코드를 우리 규칙으로 검사할 이유가 없다. **확인만 하고 넘어갈 것.**

### Task 2: 차트 데이터 가공 (순수 함수)

**Files:**
- Modify: `docs/tool/se/app.js`
- Test: `tests/se/test_se_app_js.py`

**Interfaces:**
- Produces: `CHART_SPECS` — 섹션 키 → 차트 정의
- Produces: `chartData(records, spec)` → `{labels, datasets:[{label, data}]} | null`

**여기가 이 계획의 심장이다.** 렌더는 캔버스라 테스트가 어렵지만, **무엇을 그릴지 정하는 계산은 전부 순수 함수**로 두어 node로 검증한다. SE-4c에서 `app.js` 계층의 뮤턴트는 13/13 전부 잡혔고 구멍은 CSS·렌더 쪽에만 있었다 — 그 구조를 그대로 쓴다.

**`null`을 돌려주는 경우:** 그릴 데이터가 없을 때다. 그때는 차트를 만들지 않고 표만 남긴다. **표를 없애지 않으므로 데이터가 사라지지 않는다.**

- [ ] **Step 1: 실패하는 테스트 작성**

```python
@unittest.skipUnless(_NODE, "node가 없어 app.js 순수 함수를 검증할 수 없습니다")
class TestChartData(unittest.TestCase):
    _INSIDER = """[
      {source:"elestock", repror:"오정강", rcept_dt:"20260304", sp_stock_lmp_rate:"14.13"},
      {source:"elestock", repror:"오정강", rcept_dt:"20260327", sp_stock_lmp_rate:"3.60"},
      {source:"elestock", repror:"와이어트그룹", rcept_dt:"20260415", sp_stock_lmp_rate:"6.53"}
    ]"""

    def test_groups_into_one_dataset_per_reporter(self):
        got = run_js(f'chartData({self._INSIDER}, CHART_SPECS.insider_timeline)')
        labels = sorted(d["label"] for d in got["datasets"])
        self.assertEqual(labels, ["오정강", "와이어트그룹"])

    def test_x_labels_are_sorted_by_date(self):
        got = run_js(f'chartData({self._INSIDER}, CHART_SPECS.insider_timeline)')
        self.assertEqual(got["labels"], ["2026.03.04", "2026.03.27", "2026.04.15"])

    def test_series_aligns_values_to_the_shared_x_axis(self):
        """계열마다 관측 시점이 다르다. 없는 지점은 null이어야 선이 끊긴다 —
        0으로 채우면 지분이 0이 됐다는 거짓말이 된다."""
        got = run_js(f'chartData({self._INSIDER}, CHART_SPECS.insider_timeline)')
        ohj = next(d for d in got["datasets"] if d["label"] == "오정강")
        self.assertEqual(ohj["data"], [14.13, 3.6, None])

    def test_zero_is_a_real_value_not_a_gap(self):
        got = run_js('''chartData([
          {repror:"김", rcept_dt:"20260101", sp_stock_lmp_rate:"0"},
          {repror:"김", rcept_dt:"20260102", sp_stock_lmp_rate:"1.5"}
```

```js
/** "20260415" → "2026.04.15". 날짜가 아니면 원본을 그대로 쓴다. */
function axisLabel(v) {
  const s = v === null || v === undefined ? "" : String(v);
  return /^\d{8}$/.test(s) ? s.slice(0, 4) + "." + s.slice(4, 6) + "." + s.slice(6, 8) : s;
}

/** 숫자로 읽는다. 읽을 수 없으면 null — **0으로 채우지 않는다.**
 *  0으로 채우면 "그 시점에 0이었다"는 거짓말이 된다. */
function numeric(v) {
  if (v === null || v === undefined) return null;
  const s = String(v).replace(/,/g, "").trim();
  if (s === "" || !/^-?\d*\.?\d+$/.test(s)) return null;
  const n = Number(s);
  return Number.isFinite(n) ? n : null;
}

/** 레코드 목록을 Chart.js가 받는 형태로 바꾼다. 그릴 게 없으면 null. */
function chartData(records, spec) {
  if (!Array.isArray(records) || records.length === 0 || !spec) return null;
  const rows = records.filter(function (r) { return r && typeof r === "object"; });
  if (rows.length === 0) return null;

  const xs = [];
  const seen = new Set();
  for (const r of rows) {
    const raw = r[spec.x];
    if (raw === null || raw === undefined || raw === "") continue;
    const key = String(raw);
    if (!seen.has(key)) { seen.add(key); xs.push(key); }
  }
  if (xs.length === 0) return null;
  // 전부 숫자로 읽히면 숫자로 정렬한다. 문자열 정렬이면 회차 10이 9보다
  // 앞에 와서 그래프가 거짓말을 한다. 날짜(YYYYMMDD)는 문자열 정렬이
  // 곧 시간순이라 그대로 둬도 된다.
  const allNumeric = xs.every(function (v) { return numeric(v) !== null; });
  xs.sort(allNumeric
    ? function (a, b) { return numeric(a) - numeric(b); }
    : undefined);
  const labels = xs.map(axisLabel);
  const at = new Map(xs.map(function (v, i) { return [v, i]; }));

  const datasets = [];
  if (spec.series) {
    // 같은 x에 여러 계열(계획 vs 실제 등)
    for (const s of spec.series) {
      const data = xs.map(function () { return null; });
      for (const r of rows) {
        const i = at.get(String(r[spec.x]));
        if (i !== undefined) data[i] = numeric(r[s.key]);
      }
      datasets.push({ label: s.label, data: data });
    }
  } else {
    // groupBy로 계열을 나눈다(보고자별 등)
    const groups = new Map();
    for (const r of rows) {
      const g = r[spec.groupBy];
      if (g === null || g === undefined || g === "") continue;
      const name = String(g);
      if (!groups.has(name)) groups.set(name, xs.map(function () { return null; }));
      const i = at.get(String(r[spec.x]));
      if (i !== undefined) groups.get(name)[i] = numeric(r[spec.y]);
    }
    for (const [name, data] of groups) datasets.push({ label: name, data: data });
  }

  // 값이 하나도 없으면 빈 그림이 된다 — 차트를 만들지 않는다.
  const any = datasets.some(function (d) {
    return d.data.some(function (v) { return v !== null; });
  });
  if (!any) return null;

  return { labels: labels, datasets: datasets };
}
```
