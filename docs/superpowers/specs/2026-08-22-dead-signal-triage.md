# 사장 신호 17종 분류와 1차 정리 (2026-08-22)

**결론: 17종은 한 문제가 아니라 네 문제다.** 처방이 다르므로 부류별로 나눠
처리한다. 이 문서는 분류 근거와 1차(A·D 9종) 정리 내용을 남긴다.

수치는 전부 실 DART API로 측정한 값이다. 판단 부분은 판단이라고 명시했다.

---

## 1. 방법

1년 코퍼스(2025-08-22~2026-08-22, **고유 공시 201,361건**, 정정 제외 163,429건)
에서 각 사장 신호의 **개념을 가리킬 법한 표현**을 후보로 넣고 ① 몇 건인지
② 이미 다른 신호가 잡는지 ③ 무신호인지를 쟀다.

## 3. 1차 정리 — A·D 9종

**동작은 바뀌지 않는다.** 9종의 키워드는 1년 내내 0건이었으므로 제거해도
`match_signals` 결과가 같다. 바뀌는 것은 **정직성**이다.

### 3.1 키워드 제거 + 발화 경로 명시

`NON_TITLE_SIGNALS: dict[str, str]`를 신설해 각 신호가 실제로 어떻게 다뤄지는지
값으로 남겼다 — `"structured"` / `"covered"` / `"absent"`.

taxonomy 매핑은 **지우지 않는다.** 패턴·카탈로그가 참조하기 때문이다.

### 3.2 시장 preset 정리

| preset | 전 | 후 |
|---|---|---|
| `cb_issue` | CB_BW, CB_REPAY, CB_ROLLOVER, CB_BUYBACK, EB, RCPS, TREASURY_EB | **CB_BW, EB, RCPS** |
| `reverse_split` | REVERSE_SPLIT, CAPITAL_RED, GAMJA_MERGE | **REVERSE_SPLIT, CAPITAL_RED** |

발화하지 않는 키를 남겨 두면 그 preset이 해당 유형까지 훑는다는 인상을 준다.

### 3.3 `find_risk_precedents` 정직화

이 신호들을 조회하면 설명 앞에 사실 안내를 붙인다 — "구조화 데이터로
판정됩니다" / "다른 신호가 잡습니다" / "DART 공시 제목에 등장하지 않습니다".
조회는 되는데 한 번도 안 잡히는 신호를 설명만 보여주면 "이 도구가 이걸
탐지한다"는 인상을 준다.

## 4. [정정] 패턴 영향은 넷이 아니라 **둘**이다

작업 중 "네 패턴이 관찰 불가 taxonomy를 요구한다"고 적었다가 테스트가 잡았다.
정확히 세면:

| 패턴 | 요구 taxonomy | 담당 신호 | 상태 |
|---|---|---|---|
| `zombie_ma` | 1.2 | `CB_REPAY`뿐 | **전부 일치 불가** |
| `founder_fade` | 4.1 | `MEETING_VIOL`뿐 | **전부 일치 불가** |
| `debt_spiral` | 1.5 | `CB_ROLLOVER` + **`CB_BW`** | 막히지 않음 |
| `fake_new_biz` | 5.4 | `DISTRESS_MA` + **`MGMT`** | 막히지 않음 |

1년 실측에서 `창업주 퇴장`은 겹침 284곳·전부일치 **0곳**, `무자본 M&A`는
195곳·**0곳**이었다 — **시장에 사례가 없어서가 아니라 요구 신호 하나가
관찰될 수 없기 때문이다.** 기존 기록("엄격함은 설계 의도")의 해석을 바꾼다.

`tests/test_non_title_signals.py::TestPatternImpact`가 이 구분을 기계적으로
지킨다 — `CB_BW`·`MGMT`가 죽으면 테스트가 깨지며 서술 갱신을 강제한다.

## 5. 남은 것

- **B(4종)**: 키워드 교체. 실측은 끝났고 `CIRCULAR`만 개념 재정의 선행.
- **C(3종)**: 원문·구조화 확인 계층. 이미 검증된 2단 구조가 있다
  (`FUND_OUTFLOW`+`capital_backflow`, `ACQ_REVIEW`+`fund_diversion_chain`).
  다만 `RELATED_PARTY`는 연 5,521건(하루 15건)이라 참고 강도로도 출력을 덮는다 —
  원문에 금액·이자율·자기자본 대비 같은 **파싱 가능한 필드**가 있는지 표본
  조사가 먼저다.
- `related_party_hollowing` 패턴은 요구 5개 중 3개(4.2·5.3·2.5)가 B·C에 걸려
  있다 — C를 살리는 것이 이 패턴을 되살리는 일이기도 하다.

## 6. 이 정리가 못 한 것

- **1년 한 창이다.** 0건 키워드가 영원히 0건이라는 보장은 없다. 되살리려면
  CLAUDE.md 관례대로 실측 근거를 붙이면 된다.
- **개념 자체가 유효한지는 판정하지 않았다.** "주주행동주의"가 감시 대상인지는
  별개 문제이며, 여기서는 "DART 제목으로는 잡을 수 없다"만 확인했다.
