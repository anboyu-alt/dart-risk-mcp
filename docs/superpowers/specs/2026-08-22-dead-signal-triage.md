# 사장 신호 17종 분류와 1차 정리 (2026-08-22)

**결론: 17종은 한 문제가 아니라 네 문제다.** 처방이 다르므로 부류별로 나눠
처리한다. 이 문서는 분류 근거와 1차(A·D 9종) 정리 내용을 남긴다.

수치는 전부 실 DART API로 측정한 값이다. 판단 부분은 판단이라고 명시했다.

---

## 1. 방법

1년 코퍼스(2025-08-22~2026-08-22, **고유 공시 201,361건**, 정정 제외 163,429건)

## 3. 1차 정리 — A·D 9종

**동작은 바뀌지 않는다.** 9종의 키워드는 1년 내내 0건이었으므로 제거해도
`match_signals` 결과가 같다. 바뀌는 것은 **정직성**이다.

### 3.1 키워드 제거 + 발화 경로 명시

`NON_TITLE_SIGNALS: dict[str, str]`를 신설해 각 신호가 실제로 어떻게 다뤄지는지
값으로 남겼다 — `"structured"` / `"covered"` / `"absent"`.

taxonomy 매핑은 **지우지 않는다.** 패턴·카탈로그가 참조하기 때문이다.

### 3.2 시장 preset 정리

| preset | 전 | 후 |
|---|---|---|
| `cb_issue` | CB_BW, CB_REPAY, CB_ROLLOVER, CB_BUYBACK, EB, RCPS, TREASURY_EB | **CB_BW, EB, RCPS** |
| `reverse_split` | REVERSE_SPLIT, CAPITAL_RED, GAMJA_MERGE | **REVERSE_SPLIT, CAPITAL_RED** |

발화하지 않는 키를 남겨 두면 그 preset이 해당 유형까지 훑는다는 인상을 준다.

### 3.3 `find_risk_precedents` 정직화

이 신호들을 조회하면 설명 앞에 사실 안내를 붙인다 — "구조화 데이터로
판정됩니다" / "다른 신호가 잡습니다" / "DART 공시 제목에 등장하지 않습니다".
조회는 되는데 한 번도 안 잡히는 신호를 설명만 보여주면 "이 도구가 이걸
탐지한다"는 인상을 준다.

## 4. [정정] 패턴 영향은 넷이 아니라 **둘**이다

작업 중 "네 패턴이 관찰 불가 taxonomy를 요구한다"고 적었다가 테스트가 잡았다.
정확히 세면:

| 패턴 | 요구 taxonomy | 담당 신호 | 상태 |
|---|---|---|---|
| `zombie_ma` | 1.2 | `CB_REPAY`뿐 | **전부 일치 불가** |
| `founder_fade` | 4.1 | `MEETING_VIOL`뿐 | **전부 일치 불가** |
| `debt_spiral` | 1.5 | `CB_ROLLOVER` + **`CB_BW`** | 막히지 않음 |
| `fake_new_biz` | 5.4 | `DISTRESS_MA` + **`MGMT`** | 막히지 않음 |

1년 실측에서 `창업주 퇴장`은 겹침 284곳·전부일치 **0곳**, `무자본 M&A`는
195곳·**0곳**이었다 — **시장에 사례가 없어서가 아니라 요구 신호 하나가
관찰될 수 없기 때문이다.** 기존 기록("엄격함은 설계 의도")의 해석을 바꾼다.

`tests/test_non_title_signals.py::TestPatternImpact`가 이 구분을 기계적으로
지킨다 — `CB_BW`·`MGMT`가 죽으면 테스트가 깨지며 서술 갱신을 강제한다.

## 5. 남은 것

- **B(4종)**: 키워드 교체. 실측은 끝났고 `CIRCULAR`만 개념 재정의 선행.
- **C(3종)**: 원문·구조화 확인 계층. 이미 검증된 2단 구조가 있다
  (`FUND_OUTFLOW`+`capital_backflow`, `ACQ_REVIEW`+`fund_diversion_chain`).
  다만 `RELATED_PARTY`는 연 5,521건(하루 15건)이라 참고 강도로도 출력을 덮는다 —
  원문에 금액·이자율·자기자본 대비 같은 **파싱 가능한 필드**가 있는지 표본
  조사가 먼저다.
- `related_party_hollowing` 패턴은 요구 5개 중 3개(4.2·5.3·2.5)가 B·C에 걸려
  있다 — C를 살리는 것이 이 패턴을 되살리는 일이기도 하다.

## 5.1 [2차] B 부류를 원문으로 다시 보니 — 셋은 **매핑이 부적절**했다

1차에서 "B는 키워드 교체로 살아난다"고 적었다. 원문을 떠 보니 **넷 중 셋은
taxonomy 조건과 뜻이 어긋났고, 하나는 실은 C였다.**

| 신호 | taxonomy 조건 | 후보 제목의 원문 실측 | 판정 |
|---|---|---|---|
| `CAPITAL_RED` | 2.2 "10:1 초과 주식병합을 **자본감소**로 포장" | 「주식소각결정」479건 원문: *"배당가능이익 범위 내 자기주식 소각이므로 **자본금의 감소는 없습니다**"*, *"목적: **주주가치 제고**"*(상법 343①) | ❌ **정반대** |
| `RIGHTS_UNDER` | 2.5 "실권주를 **특수관계인**이 인수" | 「주주배정후 실권주 일반공모」49건: 구주주 청약률 87%·실권주 833만주가 **일반공모에서 4,165% 청약** | ❌ **정반대** |
| `ASSET_SPIRAL` | 8.3 "**연쇄** 매각을 **헐값**에" | 단건 「유형자산처분결정」으로는 연쇄도 헐값도 판정 불가 | ❌ 조합 필요 |
| `CIRCULAR` | 3.5 "특수관계인 **연쇄** 이전, 실소유주 은닉" | 「지주회사의 자회사 편입/탈퇴」53건 — 순환출자가 아니다 | ❌ 무관 |

넷 다 `NON_TITLE_SIGNALS`에 `absent`로 편입하고 preset에서 뺐다
(`3pca`←RIGHTS_UNDER, `reverse_split`←CAPITAL_RED, `asset_transfer`←ASSET_SPIRAL).

**교훈**: "제목이 있으니 키워드만 바꾸면 된다"는 1차 판단이 성급했다. taxonomy가
요구하는 **조건**(비율·주체·연쇄·가격)을 원문과 대조해야 매핑 가능 여부를 안다.

## 5.2 [2차] `ASSET_TRANSFER`는 살아났다 — 제목 + 원문 확인

자산 처분·양도 계열은 1년 **883건이 100% 무신호**였다. 그중
「자산양도등의등록신청서」663건은 자산유동화법상 **유동화자산 양도 등록**이라
제외하면 실질 **약 200건**이다.

| 실제 표기 | 건수 |
|---|---:|
| 특수관계인에대한자산양도 | 50 |
| 비유동자산처분결정 | 48 |
| 유형자산처분결정 | 47 |
| 유형자산양도결정 | 38 |
| 영업양도결정 | 20 |

⚠ `"자산양도"` 단독 키워드는 **절대 쓰지 않는다** — 유동화 등록신청서 663건이 걸린다.

### 원문 확인 계층

taxonomy 5.3("특수관계인에게 **공정가 미만**으로 이전")은 제목만으로 판정할 수
없다 — 정상적인 자산 교체·유동성 확보가 대다수다. 다섯 서식 모두 원문에
필드가 있어 `parse_asset_disposal_detail`을 신설했다:

| 서식 | 상대방 | 관계 | 금액 | 특이 |
|---|---|---|---|---|
| 유형자산 처분결정(자율) | `3. 거래상대` | **없음** | 처분금액(원) | 상대가 개인인 경우도 |
| 비유동자산 처분결정(공정) | 거래상대방 | 회사와의 관계 | 처분가액 | **평가가액**(공정가 대비) |
| 유형자산 양도 결정(법정) | 거래상대방 회사명(성명) | 회사와의 관계 | 양도금액 | **외부평가 여부** |
| 특수관계인에 대한 자산양도(공정) | 거래상대방 | 회사와의 관계 | 양도가액 | **단위 백만원** |
| 영업양도 결정 | 양수법인 | 회사와의 관계 | 양도가액 | — |

18건 표본 실측: **상대방 100% · 금액 89% · 관계 56%**(관계 필드가 없는
「유형자산 처분결정」 서식 때문). 기존 `_confirm_outflow_counterparties` 흐름에
합류시켜 `classify_outflow_relation`·렌더링을 그대로 재사용한다.

**라이브**: 효성투자개발 — 「비유동자산처분결정」이 **계열회사(에이치에스효성
첨단소재)에 2,643억원**, 자산총액 대비 **455.63%**. 흥아해운 — 폴란드 법인에
382억원(관계 미확인).

### [수정] 확인 블록이 렌더되지 않던 경로

확인 결과는 `capital_backflow` 게이트가 **막혔을 때만** 렌더됐다. 3.1(경영권
변경)이 없어 패턴 자체가 성립하지 않는 회사는 게이트가 호출되지 않아
"누구에게 팔았나"가 통째로 사라졌다(흥아해운·효성투자개발 실측). 확인된
상대방은 패턴 주장이 아니라 사실이므로 겹침 유무와 무관하게 낸다.

`ASSET_TRANSFER`는 `AMBIGUOUS_SIGNAL_KEYS`에 넣어 헤드라인 승격을 막았다 —
score도 4→1(참고 강도)로 낮췄다.

## 5.3 [3차 준비] C 3종의 원문은 예상보다 훨씬 구조적이다

2차 말미에 C 3종의 원문을 미리 떠 봤다. **셋 다 판정에 필요한 필드가
구조적으로 들어 있다** — "제목만으로는 중립"이라던 진단이 맞았고, 원문에는
방향·조건이 다 있다.

### `RELATED_PARTY` ← 「특수관계인으로부터자금차입」 1,320건

```
나. 차입처 라인플러스(주)   회사와의 관계 계열회사
라. 차입금액 1,500  - 직전사업연도말 자기자본 -177,586  - 자기자본대비(%) 자본잠식
마. 이자율(%) 연 4.6%      바. 상환방법 만기일시상환
4. 거래상대방과의 차입총계 19,500      6. 자산총액 대비(%) 3.94
```

차입처·관계·금액·**이자율**·자기자본 대비·누적 차입총계가 전부 있다. 4.2가
요구하는 "비정상 가격의 특수관계자 거래"를 **이자율**로 확인할 수 있다.
(단위는 백만원 — 자산 처분과 같은 함정.)

### `REVENUE_IRREG` ← 「매출액또는손익구조 30% 이상 변동」 1,958건

```
매출액 8,054,627,138 / 10,503,609,086 / 증감 -2,448,981,948 / 증감비율(%) -23.3
영업이익 -815,431,280 / 403,125,614 / 흑자적자전환여부 적자전환

```

**증감비율**과 **흑자적자전환여부**가 명시된다. "변동 자체는 중립"이지만
원문에는 방향이 있다 — 적자전환 여부로 갈 수 있다.

### `CONTINGENT` ← 「소송등의판결ㆍ결정」 480건

```
3. 판결·결정내용 당사자간의 합의를 통한 소 취하
4. 판결·결정금액(원) -   자기자본(원) 750,094,583,607   자기자본대비(%) -
```

승소/패소는 `판결·결정내용` 텍스트에, 규모는 `자기자본대비(%)`에 있다.

### 3차 설계 방향(판단)

세 신호 모두 **제목으로 참고 강도만 켜고 원문으로 확인**하는 2단 구조가
그대로 들어맞는다(`ASSET_TRANSFER`·`FUND_OUTFLOW`·`ACQ_REVIEW` 선례).
다만 `RELATED_PARTY` 1,320건 + `REVENUE_IRREG` 1,958건은 **하루 9건**이라
출력 설계가 먼저다 — 전부 켜면 다른 신호를 덮는다. 임계(이자율·증감비율·
적자전환)를 원문에서 읽어 **조건을 만족할 때만** 신호로 올리는 방식이
