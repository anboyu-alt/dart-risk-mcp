## 왜

KRX 연동의 요점은 **공시와 시장 움직임을 한눈에 겹쳐 보는 것**인데 그 그림이

## 무엇을 그리나

한 패널 안에 위·아래 두 칸.

```
┌ 종가(단색 선) + 지수(가는 회색 선, 정규화) + 공시 마커(점) + 세로 표지 ┐
│                                                                        │
├ 거래량(단색 막대, 흐리게) ────────────────────────────────────────────┤
└ 월 눈금 ──────────────────────────────────────────────────────────────┘
  범례(실제로 찍힌 종류만) · 고지
```

| 요소 | 자료 | 규칙 |
|---|---|---|
| 종가 선 | KRX 일별매매정보 `close` | 단색(`--tx`). **오르내림 색 없음.** 미조회 날은 선을 끊는다(빈틈) |
| 거래량 막대 | `volume` | 단색(`--dim`), 거래량 0인 날은 막대 없음 |
| 지수 선 | `idx/kospi_dd_trd` 「코스피」 / `idx/kosdaq_dd_trd` 「코스닥」(corp_cls·시장 판별 결과로 짝) | 가는 회색 선. **구간별 정규화** — 창 시작일(과 기준가 조정일 다음 날)마다 종목 종가에 맞춰 `stock[t0] × idx[t]/idx[t0]`. 그래야 종목과 지수가 같은 날 같은 자리에서 출발하고, 분할·병합으로 종목 선이 뛰어도 지수가 엉뚱한 높이에 남지 않는다 |
| ① 관찰 신호 접수일 | `CUR.observedEvents` | 종가선 위의 마커. **색은 하나(`--amber`), 모양이 관찰 순서**(`priority` — `first` ◆ · `watch` ● · `context` ○ 속 빈 원). 같은 날 여러 신호는 마커 하나 + 「×N」. 접수일이 휴장이면 **다음 거래일**에 놓고 툴팁에 원 접수일을 적는다. 클릭: DART 원문(`dartUrl`) |
| ② 기준가 조정일 | `priceBreaks(rows)` | 점선 세로선 + 「기준가 ×0.20」 라벨. 종가는 원값 그대로 |
| ③ 매매정지 구간 | 거래량 0 연속 구간(1일 이상) | 빗금 띠. 라벨 「거래량 0 · N거래일」 — 「정지」라 단정하지 않는다(정지는 DART 공시가 말한다) |
| ④ 코스닥 소속부 변경일 | `sect` 변화(`windowOverview.sect_changes`) | 세로선 + 「→ 관리종목(소속부없음)」 라벨. 유가증권은 이 필드가 비어 없음 |

- **마커를 카테고리 색으로 칠하지 않는 이유(실측)**: 뷰어 카테고리 팔레트 `--c1~c8`을 `dataviz` 검증기(`validate_palette.js`, 다크 표면 `#11151d`)에 넣으니 **인접 쌍 `--c3`↔`--c2`가 정상 시각에서도 ΔE 11.2(하한 15)·색약 4.0**으로 실패한다(밝기 밴드·채도 하한도 실패). 피드는 라벨 텍스트가 곁에 있어 색이 보조인데 차트 마커는 색만 남는다. 팔레트 교체는 뷰어 전체 사안이라 이 작업 밖이고, 차트는 **강조형**(한 색 + 모양)으로 간다 — 마커의 정체는 툴팁·아래 표·범례가 말한다.
- **호버(기본 탑재)**: 세로 십자선이 가장 가까운 거래일에 붙고 툴팁 하나에 그날의 종가·등락(KRX `FLUC_RT`)·거래량·정규화 지수·그날 마커(신호 라벨·공시명·원 접수일)를 함께 적는다. 값은 `textContent`로 넣는다(제목은 DART 원문 데이터). 마커 자체의 명중 영역은 24px. 키보드: 마커는 `<a>`라 포커스로 툴팁이 뜬다.
- 눈금: x는 월 초, y는 오른쪽 종가(원, 자릿점). 거래량 칸은 최대값 한 눈금. 격자는 1px 실선 `--line`(점선 금지 — 점선은 조정일·소속부 같은 **표지**에만 쓴다).
- 종목 선·지수 선 두 시리즈라 **범례를 늘 낸다**(선 모양 키). 마커 범례는 실제로 찍힌 모양만.
- SVG는 `viewBox`로 격자 트랙 폭에 맞춘다(`.deepgrid` 2열 ~510px에서도 읽혀야 한다). 세로 표지·라벨이 겹치면 라벨을 위아래로 번갈아 놓는다.
- 순수 SVG, 외부 의존 0(뷰어 원칙). 색·마크는 `dataviz` 스킬의 규칙을 따라 구현한다.

## 창·데이터

- **차트 창 = 스캔 창**(`LOOKBACK_DAYS`, 기본 365). 3Y·5Y 스캔이면 **최근 365일만** 그리고 「스캔 창 N년 중 최근 1년만 그립니다」를 적는다(MCP가 400일 넘는 창에서 시세를 생략하는 것과 같은 판단).
- 종목 시세는 **창 시작 100일 앞부터** 받는다 — 창 초입 사건의 기준선(60거래일) 계산이 지금 표와 같게. 지수는 **창 안만** 받는다(정규화에 기준선이 필요 없다).
- 비용(1년, cold): 종목 ≈ 310콜 + 지수 ≈ 245콜 = **약 555콜**, 동시 4 → 약 2분 20초. 본인 키·일 1만 한도 안. 이후는 캐시(0콜).
  - 패널 호출 예산 `KRX_CALL_BUDGET` 120 → **340**(종목 — 달력 465일의 평일 332일을 한 번에) + 지수는 별도 예산 **270**(달력 365일의 평일 261일). 첫 판 320/260은 로컬 실측에서 늘 12일/1일이 남았다. 예산에 걸린 날은 `uncovered`로 남기고 「N일 미조회 — 다시 펼치면 이어 받습니다」.
  - **점진 표시**: 종목 시계열이 끝나면 차트를 먼저 그리고, 지수는 받는 대로 덧그린다(기다리는 동안 빈 화면이 아니다). 진행 문구 「종목 N/M거래일 · 지수 N/M」.
  - 행 캐시 `dart_tool_krx_rows` 3,000 → **6,000**건(종목 310 + 지수 245 = 회사당 약 555행, 10곳분). 지수 행은 같은 캐시에 `api|date|IDX_NM` 키로.
- 미조회·발표 전(`pending`) 날은 선을 끊는다. **없는 값을 잇지 않는다**(스파크라인과 같은 규칙).

## 릴레이

`/api/krx`에 지수 2종을 더한다 — `api/krx.js`·`relay/worker.js`·`scripts/dev_relay.py` 세 곳 동시(기존 화이트리스트 관례).

- `api=kospi_dd_trd|kosdaq_dd_trd` → KRX 경로가 `svc/apis/idx/...`(종목은 `sto/`)이라 api → 경로 접두를 표로 가른다.
- 지수 응답은 하루치 **모든 지수**(코스피 54행·코스닥 40행)라 릴레이가 **`IDX_NM`이 정확히 「코스피」/「코스닥」인 한 행만** 돌려준다(종목이 `ISU_CD` 한 행만 돌려주는 것과 같은 이유). `isu` 인자는 지수에서 받지 않는다.
- 사용자 키 전달·`no-store`·쿼터 없음·서버 키 참조 0 — 종목과 같다(약관 제11조). `tests/test_viewer_krx_relay.py`의 세 곳 대조에 지수 두 api를 더한다.
- 정규화 행 키: `{date, close, fluc_rt, mktcap}`(`CLSPRC_IDX`·`FLUC_RT`·`MKTCAP`) — 종목 행과 같은 이름을 써서 `priceBreaks`류를 재사용하지 않는다(지수에 기준가 조정은 없다). 실측(2026-09-23, 20260918): 코스피 54행·코스닥 40행, 키 12종 공통 `ACC_TRDVAL ACC_TRDVOL BAS_DD CLSPRC_IDX CMPPREVDD_IDX FLUC_RT HGPRC_IDX IDX_CLSS IDX_NM LWPRC_IDX MKTCAP OPNPRC_IDX`, 첫 행이 「코스피 (외국주포함)」이라 **정확 일치**로 고른다. 휴장일은 종목과 같은 `{"OutBlock_1":[]}`. 응답 15KB·11KB(종목 600KB보다 훨씬 가볍다). core에는 상수(`KRX_INDEX_API_IDS`·`KRX_INDEX_BASE`·`KRX_INDEX_NAMES`)와 순수 `_normalize_index_row`만 두고 fetch는 두지 않는다(MCP는 지수를 쓰지 않는다 — 로컬 릴레이가 그 함수를 import해 세 릴레이의 정규화가 갈리지 않게 한다). 실측 키는 `tests/fixtures/api/krx_response_keys.json`에 고정.

## 표·제목·고지

- 기존 사건 표는 차트 아래 그대로. 상한 3 → **12건**(MCP와 같음). 초과분 「관찰 N건 중 최근 12건 · K건 생략」. 각주 배치는 2026-09-23 수정(표 아래) 그대로.
- 절 제목 「MARKET REACTION — 공시와 시장 (1년)」. 펼침 문구 「펼쳐서 조회 — 1년 시세·거래량·지수 위에 관찰 신호 N건」.
- 고지: 「한국거래소 통계정보」 · 접수일≠사건일·장 마감 후 접수는 다음 거래일 · 정정 제외 · 기준가 조정 앞뒤 종가는 원값 · **지수는 창 시작일(과 조정일)마다 종목에 맞춰 정규화한 상대 움직임**이라 지수 값 자체가 아니다 · 미조회 N일.
- 무판정: 지수와의 차이(초과수익)를 **수치로 내지 않는다** — 겹쳐 보이는 것까지가 이번 범위(DEFERRED 17의 「병기」 선택지). 「급등·급락·이상·과열」 없음(`test_viewer_market_panel`의 판정어 검사가 차트 함수까지 덮도록 넓힌다).

## 구조·테스트

- 순수 함수 둘로 가른다 — `marketChartModel(rows, idxRows, events, opts)` → `{points, gaps, volume, idxPoints, markers, breaks, haltBands, sectMarks, xTicks, yTicks}` / `marketChartSVG(model)` → 문자열. 이름은 `Model`/`SVG` 접미로 core와 짝지어지지 않게(쌍둥이 패리티 가드).
- `marketChartModel`을 node 하네스로 잠근다: 빈틈(미조회) 처리 · 휴장일 접수 마커의 다음 거래일 배치 · 같은 날 신호 묶기 · 거래량 0 띠 · 소속부 변경 · 기준가 조정 구간별 지수 정규화 · 지수가 없을 때 종목만.
- `marketChartSVG`: 태그 균형(`test_viewer_deep_grid`의 균형 검사 방식) · 판정어 0 · 오르내림 색 클래스 없음(`test_viewer_sparkline`과 같은 계약).
- 고지 사실: `test_viewer_notice_facts` 층①에 「N일 미조회」·「최근 12건 · K건 생략」 앵커 추가.
- 릴레이: 세 곳 화이트리스트·경로 접두·IDX_NM 필터·`no-store` 대조.
- 라이브: 코아스(유가)·CSA 코스믹(코스닥, 기준가 조정 2회)·삼성전자(사건 적음) — 로컬 릴레이와 프로덕션 릴레이 양쪽, 스크린샷. 콘솔 오류 0.
