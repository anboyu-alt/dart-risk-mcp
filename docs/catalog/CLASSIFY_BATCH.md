# 배치 분류 지시서 (세션/서브에이전트용)

이 문서는 금감원 보도자료 카탈로그 파이프라인의 **오프라인 백필 2차 분류** 단계를
수행하는 세션(서브에이전트)이 읽는 단일 기준 문서입니다. 배치가 90개 안팎이므로,
서로 다른 세션이 이 문서 하나만 보고도 항상 같은 방식으로 판단해야 합니다.

이 작업은 1회성 백필입니다(월간 증분은 API 경로를 그대로 씁니다). 결과는
`merge_batches.py`가 형식을 엄격히 검증합니다 — **아래 스키마를 정확히 지키세요.**
taxonomy id 오타 하나가 그 유형의 사례를 조용히 사라지게 만듭니다.

---

## 1. 입력: 배치 파일

경로: `data/catalog/batches/batch-NNN.jsonl` (NNN은 3자리, 예: `batch-000.jsonl`)

한 줄이 레코드 하나입니다. 필드:

| 필드 | 의미 |
|---|---|
| `id` | 원본 게시물 id. **결과에 그대로 써야 합니다** (변형·재포맷 금지) |
| `date` | 게시일 (YYYY-MM-DD) |
| `title` | 보도자료 제목 |
| `dept` | 담당부서 |
| `url` | 원문 URL |
| `keep` | 항상 `true` (1차 스크리닝 통과분만 배치에 들어옵니다) |
| `category_hint` | 1차 스크리닝이 남긴 참고용 대분류 힌트(1~8 또는 빈 문자열). **참고만 하고 맹신하지 마세요** — 제목·부서만 보고 매긴 값입니다 |
| `body` | 본문 텍스트. 아래 `body_source`에 따라 품질이 다릅니다 |
| `body_source` | `pdf`(PDF 전문 확보 성공) / `page`(게시판 상세 페이지 요약) / `title_only`(본문 확보 실패, 제목만) |
| `body_chars` | `body` 길이(참고용) |
| `attachment_urls` | 첨부 다운로드 URL(참고용, 분류에 직접 쓸 필요 없음) |

**`body_source`가 `page` 또는 `title_only`인 레코드는 전문이 아니라 요약/제목뿐입니다.**
이런 레코드는 적발기법(`techniques`)·제재(`sanctions`)·근거법령(`laws`)을 구체적으로
추출하기 어렵습니다. 억지로 채우지 말고, 본문에서 확인되지 않으면 빈 배열로 두고
`confidence`를 `low`로 낮추세요.

**`body_source`가 `pdf`여도 본문에 적발 내용이 없을 수 있습니다.** PDF 전문 확보에는
성공했지만, 텍스트 레이어에 작성부서·책임자·담당자 전화번호·배포일 같은 보도자료
머리말만 있고 정작 적발 사실 서술이 비어 있는 경우가 있습니다 — 특히 오래된 자료에서
그렇습니다(실측: id 7991 "자본시장 불공정거래 혐의에 대한 조사결과 조치", 2010년
자료, PDF 전문 378자 전량이 "책 임 자 최준우 과장(2156-9910) … 배 포 일 2010. 8.
25.(수) 총 5매" 형태의 머리말이었고 적발 내용은 없었습니다). `pdf` 라벨은 "본문
텍스트를 확보했다"는 뜻이지 "본문에 알맹이가 있다"는 뜻이 아닙니다 — **라벨이 아니라
`body`의 실제 내용을 읽고 판정하세요.** 읽어보니 적발 내용이 실제로 없으면
`body_source`가 `pdf`이더라도 `techniques`/`sanctions`/`laws`는 빈 배열, `confidence`는
`low`로 두세요.

## 2. 출력: 결과 파일

경로: `data/catalog/results/batch-NNN.result.jsonl` (입력 파일명의 `batch-NNN`을 그대로 씁니다)

**배치의 모든 레코드에 대해 결과 한 줄씩 반드시 있어야 합니다.** 하나라도 빠지면
`merge_batches.py`가 "keep=true인데 결과가 없다"는 오류로 보고하고, 그 사례는
최종 카탈로그에서 조용히 누락됩니다.

### 필수 필드 (전부 있어야 합니다)

| 필드 | 타입 | 의미 |
|---|---|---|
| `id` | string | **입력 레코드의 id를 그대로 사용** |
| `date` | string | 입력의 `date`를 그대로 복사 |
| `title` | string | 입력의 `title`을 그대로 복사 |
| `url` | string | 입력의 `url`을 그대로 복사 |
| `taxonomy_ids` | list[string] | 아래 taxonomy 45개 중 해당하는 id들. **확신 없으면 빈 배열** |
| `techniques` | list[string] | 본문에 실제로 등장하는 적발 기법·수법 (짧은 명사구) |
| `sanctions` | list[string] | 본문에 실제로 등장하는 제재 내용(과징금, 형사고발, 영업정지 등) |
| `laws` | list[string] | 본문에 실제로 등장하는 근거 법령명 |
| `summary` | string | 1~3문장 사실 요약 (판정·형용사 없이 무슨 일이 있었는지) |
| `confidence` | string | `high` / `medium` / `low` — taxonomy 매핑에 대한 확신도 |
| `body_source` | string | 입력의 `body_source`를 그대로 복사 (분류자가 만들지 않음) |

> `agency`(보도기관명)는 이 목록에 없습니다 — **결과 파일에 쓸 필요가 없습니다.**
> 현재 수집원이 금융감독원 보도자료 게시판 하나뿐이라 값이 항상 고정이므로,
> 병합 단계(`merge_batches.py`)가 자동으로 `"금융감독원"`을 채웁니다. 분류자가
> 이 필드를 채우거나 추측할 필요가 없습니다.

### 완성된 예시 1건

```json
{"id": "20240118-000123", "date": "2024-01-18", "title": "OO 주식회사 대표이사 등 불공정거래 조사결과 조치", "url": "https://www.fss.or.kr/fss/bbs/B0000188/view.do?nttId=123456", "taxonomy_ids": ["7.1", "3.6"], "techniques": ["미공개 정보를 이용한 사전 매도", "임원 특수관계인 명의 차명계좌 활용"], "sanctions": ["과징금 5억원 부과", "검찰 고발"], "laws": ["자본시장법 제174조(미공개중요정보 이용행위 금지)"], "summary": "OO 주식회사 대표이사가 감사의견 비적정 공시 전 특수관계인 명의로 보유주식을 매도해 손실을 회피한 사실이 적발되어 과징금과 검찰 고발 조치되었다.", "confidence": "high", "body_source": "pdf"}
```

(한 줄에 JSON 객체 하나 — JSONL. 위 예시는 가독성을 위해 줄바꿈 없이 그대로 한 줄로 저장하세요.)

## 3. 판정 규칙

- **억지로 끼워 맞추지 마세요.** 45개 유형 중 어디에도 명확히 해당하지 않으면
  `taxonomy_ids: []`로 두세요. 빈 배열은 실패가 아니라 **신규 유형 후보**로
  `gaps.py` 리포트에 그대로 들어갑니다 — 이게 이 파이프라인이 새 수법을
  발견하는 방식입니다.
- 확신이 없으면 `confidence: "low"`를 쓰세요. 억지로 `high`를 주지 마세요.
- 여러 유형에 걸치면 `taxonomy_ids`에 복수 id를 넣어도 됩니다(배열이므로).
- `techniques` / `sanctions` / `laws`는 **본문에 실제로 쓰여 있는 내용만** 적으세요.
  taxonomy 설명이나 일반 상식으로 추측해서 채우지 마세요 — 본문에 없으면 빈 배열입니다.
- `category_hint`는 힌트일 뿐 정답이 아닙니다. 본문을 읽고 판단하세요.
- `body_source`가 `page`/`title_only`면 위에서 설명한 대로 적발기법 추출이
  제한된다는 점을 감안해 보수적으로(낮은 confidence, 빈 배열 허용) 판정하세요.
- `body_source`가 `pdf`라고 해서 본문에 알맹이가 있다고 가정하지 마세요. 머리말뿐인
  PDF도 있습니다(위 §1 참고). 항상 `body`를 직접 읽고, 적발 내용이 없으면 `page`/
  `title_only`와 동일하게 보수적으로 판정하세요.

## 4. Taxonomy 45개 전체 목록

`id | 명칭 | 설명`. 카테고리별로 묶여 있습니다.

### 카테고리 1 — 전환사채·채무 조작 (Convertible Bond & Debt Manipulation)

| id | 명칭 | 설명 |
|---|---|---|
| 1.1 | 리픽싱 (Refixing) | DART 공시 없이 전환가액을 하향 조정 |
| 1.2 | 자회사 배당을 통한 CB 조기상환 | 자회사·비상장 계열사 배당금으로 CB를 상환(영업활동과 무관한 자금) |
| 1.3 | 특수관계인 대상 교환사채(EB) 발행 | 특수관계인에게 유리한 조건으로 EB 발행 |
| 1.4 | RCPS 숨은 희석 | 보장수익·자동전환 조건이 붙은 상환전환우선주 발행 |
| 1.5 | CB 발행-상환 순환(EB 돌려막기) | 만기 도래 CB를 갚기 위해 계속 새 CB를 발행, 순현금흐름 악화 |
| 1.6 | 저가 CB 매입상환 | 회사가 자기 CB를 시장가 대비 10~20% 낮게 되사들임 |
| 1.7 | 자사주 연동 EB | 신주가 아닌 자사주에 연동된 EB/CB 발행 |

### 카테고리 2 — 자본구조 조작 (Capital Structure Manipulation)

| id | 명칭 | 설명 |
|---|---|---|
| 2.1 | 무상감자(주식병합) | 5:1 이상의 과격한 병합으로 부실한 재무상태를 가림 |
| 2.2 | 자본감소(병합을 통한 희석) | "자본감소"로 발표되는 10:1 이상 병합 |
| 2.3 | 감자·합병 동시 진행 | 감자 발표와 합병 발표가 30일 이내 동시 발생 |
| 2.4 | 제3자배정 유상증자 | 제3자에게 우호적 조건으로 배정하는 유상증자 |
| 2.5 | 공모(청약) 미달 | 유상증자 청약이 미달되어 특수관계인이 실권주를 인수 |
| 2.6 | 자사주 매입 후 재발행 패턴 | 감자 목적 매입 후 즉시 EB/CB로 재발행 |
| 2.7 | 자본 이벤트 과다 반복 | 12개월 내 증자·감자·자사주·CB/BW/EB 등 자본 이벤트가 비정상적으로 집중(부호: `CAPITAL_CHURN`) |
| 2.8 | 자기주식 신탁 우회 취득 | 신탁계약을 통해 직접 매입 신고 없이 자사주 매입 효과를 거둠 |

### 카테고리 3 — 지배구조·경영권 (Ownership & Control)

| id | 명칭 | 설명 |
|---|---|---|
| 3.1 | 채무의 주식전환에 의한 최대주주 변경 | CB/EB 전환으로 소유권 이전, 창업주 지분 희석 |
| 3.2 | 지배주주의 저가 지분 매각(경영권 이양) | 창업주가 시장가 대비 크게 낮은 가격에 지분 매각 |
| 3.3 | 행동주의 펀드의 이사회 장악 | 외부 투자자가 이사회 교체를 강제, 경영진 축출 |
| 3.4 | 경영권 승계 분쟁 | 창업주와 외부 투자자 간 대표이사 승계를 둘러싼 충돌 |
| 3.5 | 특수관계자 순환 거래 | 특수관계자 연쇄를 통한 지분 이전, 최종 소유자 은폐 |
| 3.6 | 부정적 공시 직전 내부자 매도 | 임원·대주주 매도 직후 30일 내 감사의견 비적정·부도·횡령·조회공시 등 발생 (`INSIDER_PRE_DISCLOSURE`) |
| 3.7 | 최대주주 주식담보제공계약 | 최대주주가 보유주식을 담보로 제공(체결·해제·취소). 인수자금이 주식담보대출인 무자본 M&A 사례와 연관되나, 정상적 주담대도 흔해 참고 수준 |

### 카테고리 4 — 거버넌스·공시 (Governance & Disclosure)

| id | 명칭 | 설명 |
|---|---|---|

| 4.2 | 특수관계자 비정상 가격 거래 | 특수관계자 거래에서 유의미한 가격 왜곡 |

### 카테고리 5 — 기업활동 조작 (Corporate Action Manipulation)

| id | 명칭 | 설명 |
|---|---|---|
| 5.1 | 주식분할+배당 결합 | 주주 수를 부풀리기 위한 주식분할과 배당 동시 발표 |
| 5.2 | 자사주 매입 + 마이너스 영업현금흐름 | 영업현금흐름이 마이너스인데도 자사주 매입 발표 |
| 5.3 | 시장가 이하 자산 양도 | 특수관계자에게 공정가치 이하로 자산 양도 |
| 5.4 | 재무위기 중 인수합병 | 재무 곤경 중 무관한 사업 다각화 M&A 발표 |
| 5.5 | 비대칭 가치배분 분할 | 특수관계자에게 불균형하게 가치가 이전되는 회사 분할 |
| 5.6 | 적자 중 배당 유출 | 당기순이익 적자임에도 현금배당 결정(`DIVIDEND_DRAIN`) |
| 5.7 | 인수자 측으로의 자금 유출 | 금전대여·채무보증·담보제공·유형자산양수처럼 회사 자금·신용이 밖으로 나가는 거래. 경영권 변경 직후 발생하면 관찰 포인트(`FUND_OUTFLOW`) |
| 5.8 | 상대방 확인이 필요한 인수 | 영업양수·타법인주식및출자증권양수 결정. 정상 M&A가 대다수라 그 자체로는 판단 근거가 아니며 상대방·가액·외부평가를 원문에서 확인해야 함(`ACQ_REVIEW`) |
