# 공개 뷰어 접속 분석 — 운영 안내

공개 리스크 뷰어(`docs/tool/index.html`)의 접속 기록을 수집해 운영자만 보는
대시보드다. 이 문서는 배포 절차와 수집 범위를 적는다.

## 1회 셋업

### ① Supabase 스키마

Supabase SQL 편집기에 `tool_server/schema_analytics.sql` 전문을 붙여넣어
실행한다. 재실행해도 안전하다(`if not exists` / `create or replace`).

테이블 `viewer_events` 하나와 집계 뷰 4개가 만들어진다. RLS를 켜고 정책을
두지 않으므로 `service_role` 키를 가진 서버 함수 외에는 읽을 수도 쓸 수도
없다.

### ② 접근 토큰 생성

```bash
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

### ③ Vercel 환경변수

| 변수 | 값 |
|---|---|
| `SUPABASE_URL` | Supabase 프로젝트 URL (SE와 같은 값이면 그대로) |
| `SUPABASE_SERVICE_KEY` | service_role 키 |
| `OPS_TOKEN` | ②에서 만든 문자열 |

`OPS_TOKEN`을 설정하지 않으면 `/api/stats`는 **503으로 닫힌다**. 토큰 없이
열린 채로 도는 것보다 안 도는 게 낫다는 판단이다.

## 사용

대시보드: `https://<배포주소>/ops-762b24e0.html`

첫 접속 때 토큰을 한 번 입력하면 `localStorage`에 보관돼 이후 자동으로
쓰인다. "토큰 해제" 버튼으로 지운다.

화면 4개:

| 탭 | 내용 |
|---|---|
| 조회 회사 | 어떤 기업이 몇 번 조회됐는지 순위 |
| 유입·지역·기기 | 유입 사이트 URL, 국가·도시, 브라우저·OS·기기 |
| 트래픽 추이 | 일별 방문자·페이지뷰·스캔 꺾은선 |
| 방문자 | 방문자 목록(IP·지역·기기) → 행 클릭 시 조회 순서 타임라인 |

기간 필터(오늘/7일/30일/1년)는 모든 탭이 공유한다.

## 수집 항목

| 항목 | 출처 |
|---|---|
| 접속 IP (원본) | `x-forwarded-for` 첫 항목 |
| 방문자 ID | 쿠키 `dv_id` (UUID, 1년) |
| 국가·지역·도시 | Vercel `x-vercel-ip-*` 헤더 |
| User-Agent 원본 + 브라우저·OS·기기 | 요청 헤더 파싱 |
| 유입 URL | `document.referrer`에서 쿼리스트링 제거 |
| 조회 회사명·종목코드 | 뷰어 스캔 성공 시 |
| 화면 해상도·언어·경로 | 브라우저 |

이벤트 4종: `pageview`(진입) · `scan`(기업 스캔) · `compare`(겸직 비교) ·
`doc`(공시 원문 열람).

**사용자의 DART API 키는 수집하지 않는다.** 클라이언트가 보내지 않고,
서버도 화이트리스트 밖 필드를 버린다(`tests/test_tool_server_track.py`가
이를 고정한다).

## 알아둘 것

- **개인정보 처리에 해당한다.** 원본 IP와 쿠키를 저장하므로 국내법상 처리방침
  고지 대상이다. 뷰어 면책 문구 끝에 수집 사실 한 줄을 넣어 뒀다. 별도
  처리방침 페이지가 필요한지는 운영자 판단이다.
- **보관기간 자동 삭제가 없다.** 필요하면 Supabase에서 직접 지운다:
  ```sql
  delete from viewer_events where ts < now() - interval '90 days';
  ```
- **"방문 연인원"은 실제 순방문자보다 크다.** 집계 뷰가 날짜별로 쪼개져
  있어 같은 사람이 이틀에 걸쳐 보면 2로 센다. 기간 필터를 유지하기 위한
  트레이드오프이며 화면에도 같은 설명을 적어 뒀다.
- **DART 릴레이(`api/[endpoint].js`)에는 로깅이 없다.** 그쪽은 "키·파라미터·
  응답을 저장하지 않는 무상태 통과"가 명시된 신뢰 경계라 손대지 않았다.
  수집은 `/api/track`에서만 일어난다.
- **봇 트래픽을 자동으로 걸러내지 않는다.** UA에서 봇으로 판별되면
  `device = 'bot'`으로 표시만 하고 집계에는 그대로 포함된다.
